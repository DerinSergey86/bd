Реляционная база данных (РБД) — это способ организации данных в виде связанных между собой таблиц (отношений), где информация структурирована по строкам и столбцам. Она основана на модели, предложенной Эдгаром Коддом, и использует язык SQL для управления данными, обеспечивая высокую целостность, точность и предсказуемость информации.

Основные характеристики реляционных баз данных:
Табличная структура: Данные хранятся в таблицах (отношениях), где строки представляют собой уникальные записи (кортежи), а столбцы — атрибуты (характеристики) данных.
Связи (Relations): Таблицы связаны между собой с помощью общих полей, что позволяет структурировать сложные данные.
Первичные и внешние ключи: Каждая таблица имеет первичный ключ (уникальный идентификатор строки), а внешние ключи используются для создания ссылок между таблицами.
Язык SQL: Для создания, поиска, обновления и удаления данных используется универсальный Structured Query Language.
