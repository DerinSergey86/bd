Docker-контейнер — это стандартизированный, изолированный и легковесный пакет, содержащий всё необходимое для запуска приложения: код, библиотеки, зависимости и настройки. Это автономный программный модуль, работающий на общей ОС, обеспечивающий одинаковое поведение программы на любых машинах.

docker compose up - создание контейнеров на базе образов
docker compose up -d - запуск в фоновом режиме
docker compose stop - остановка процесса
docker compose start -включаем процесс
docker compose ps — посмотреть статус запущенных контейнеров.
docker compose stop — временно остановить работу контейнеров.
docker compose down — полностью остановить и удалить контейнеры.
docker compose logs — посмотреть логи работающих контейнеров.
docker images - показывает образы контейнеров
nano имя файла - режим текстового редактирования
 - эти программы выполняются из каталога, где лежит docker-compose.yaml

 - - образы не меняются - это шаблоны из которых запускаются контейнеры 

в браузере вводим адрес http://192...:8081 (адрес:порт) 

в консоле, по команде cat docker-compose.yaml у контейнера mariadb в enviroments указаны пользователи и пароли

открывается клиент к базе данных mariadb

смотрим на контейнер pgadmin в консоле
в браузере вводим адрес http://192...:8080 (адрес:порт)
у контейнера pgadmin в enviroments указаны дефолтные емейл и пароль
(нажать) добавить новый сервер
во вкладке соединение надо указать куда подключаемся 
понимая, что оба контейнера работают в одной сети внутри докера, хост, для того, чтобы phpmyadmin увидел postgres будет называться: postgres
у контейнера postgres в enviroments указано имя пользователя и пароль и база данных
после ввода, нажать сохранить

видно, что pgadmin взаимодействует с субд(система кправления базами данных) postgres. phpmyadmin взаимодействует с mariadb
